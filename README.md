## 优惠叠加的几条限制，买之前先看清

优惠力度大，限制也写得明白。以下几条都来自官方公示规则和公开测评，值得下单前过一遍：

- **优惠券一般不能多张同时用**。常见情况是一张券叠加长期付费折扣，而不是两张券叠加。
- **券有适用产品和付费周期**。年付专用券用在月付订单上不生效，先看清券面说明。
- **7天无理由退款每个账号只有3次**，且只针对月付及以上产品，日付不支持退订；退订后消耗的优惠券和积分不退回。
- **1元试用产品不在7天退款范围内**，试用到期后12小时内未续费会自动回收，数据要提前备份。同一地域每周可试用1次。
- **流量型套餐用超流量会限速**（通常降到1Mbps左右），可以单独买流量包恢复高速；不限流量型则带宽本身较低，两者要在下单时选对。
- **公网 IP 单独计价**，普通 IP 通常几元一个/月，高防或住宅 IP 更贵；比价时要把它算进去。
- **服务器默认封禁 25 端口**，想拿来做邮件发送的，这条路走不通。
